# ftc-Station-Broadcast
> This is a station broadcasting system developed in Minecraft using the Computercraft and Create mods, referring to the station broadcasting system of   Japan Railway JR
---
**The "setup.lua" is the client installation program**
## How To Use
### 1. Place the Peripheral device like this
- **bottom**: Final tone Modem (computercraft:wireless_modem_advanced)
- **top**: Wired modem (computercraft:wired_modem) -> Network cable (computercraft:cable) -> Wired modem (computercraft:wired_modem) ->" speaker (computercraft:speaker
- **Side** (right/left) : Advanced Display (computercraft:monitor_advanced)
- **back**: Train station (create:track_station)
### 2. Download the "setup.lua" and upload to your computer in Minecraft
### 3. Run "setup.lua" and follow the guidance.
> You can find the departure music in **FSE Server-Railway Transport Information**`https://docs.qq.com/smartsheet/DV29hVGFWQnVkZ3Z4?tab=tITg8m&viewId=vZm27T`
### 4. Reboot your computer.
Check if the countdown is normal
### 🎉Congratulations! You have completed the installation
